# lands-of-nameless-king



A grid-based logic puzzle game where players divide royal farmland into valid territories by placing walls under strict adjacency rules. Includes three difficulty levels, real-time connectivity validation via Breadth-First Search (BFS), and persistent leaderboards.

## 🛠️ Technologies Used
* **JavaScript (ES6+):** Custom state management, BFS algorithm for real-time rule checking, DOM event delegation, and `requestAnimationFrame` timer.
* **HTML5 & CSS3:** Responsive board layouts built with CSS Grid (zero external libraries or frameworks).
* **Web Storage API (`localStorage`):** Persistent game saves and per-level leaderboards.

## 🚀 How to Run
1. Clone or download the repository.
2. Open `index.html` directly in any modern web browser (no server or dependencies required).
